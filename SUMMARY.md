For this CSC-299 final project, I built a complete command-line software system that includes a personal task manager, a personal knowledge management system (PKMS), a chat interface, and an AI agent. Throughout the entire process, I used different kinds of AI-coding assistance, including ChatGPT, GitHub Copilot, and some planning notes I made with the help of AI. This summary explains how I developed the project, the steps I took, what worked well, and what didn’t work as smoothly.

When I first started the project, I used ChatGPT mainly as a planning tool. Before writing any code, I asked for help breaking the project into the four major modules the assignment required. ChatGPT helped me figure out the folder structure, the idea of using Click for the command-line interface, and how to store state using JSON files. This part helped a lot because it gave me a starting point instead of staring at a blank project. I also used this early planning phase to create the prototypes (tasks1, tasks2, tasks3, tasks5, etc.) that the assignment required.

Once I moved into writing the actual code, I used both ChatGPT and GitHub Copilot in different ways. ChatGPT was more useful for bigger ideas, like fixing import errors, helping me understand why the package structure wasn’t working, or telling me how to register Click commands correctly. GitHub Copilot helped more with small stuff, like filling in function bodies or suggesting simple code blocks. Sometimes Copilot guessed things wrong or created code that didn’t quite match my project layout, so I had to delete or fix its suggestions. So overall, ChatGPT was more helpful for thinking and debugging, while Copilot helped with typing.

There were several false starts along the way. One of the biggest problems I had was getting the folder structure right. At one point, I accidentally had two folders named final_system, and my modules weren’t being imported correctly. This caused a lot of “module not found” and “no such file” errors. Another issue was with the data folder. The JSON files (tasks.json and pkms.json) were supposed to store the state for the task manager and PKMS, but at first they were saved in the wrong place, causing FileNotFoundError. Fixing the path in the storage module finally solved that.

The AI agent module also took some trial and error. At one point I accidentally pasted the agent code inside cli.py, which made it impossible for Click to register the commands. Once I separated the files properly and reinstalled the package with uv pip install -e ., the commands finally showed up. I also had to learn how to set the OPENAI_API_KEY environment variable so that the agent could actually connect to GPT-5-mini. That part didn’t work the first few tries, but once I exported the key in the same terminal session, the summaries worked perfectly.

Testing was something I did a lot throughout the project. Almost every time I added or changed code, I used the uv run commands like tasks add, pkms list, or agent summarize-notes to make sure everything still worked. This helped me catch problems early each time I broke something.

Overall, using AI tools made this project way more manageable. ChatGPT helped me understand errors and structure the whole project, while Copilot helped speed up writing code. Some things didn’t work right away, especially with imports and file paths, but those ended up teaching me how Python packages and environments actually work. In the end, I ended up with a fully working system that meets all the project requirements and runs through a single command-line interface.
